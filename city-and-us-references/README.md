## Current acceptance priorities
1. Character remains visible: camera collision, obstructing wall/roof cutaways, smooth close-follow and whole-house views.
2. Compact circular minimap near the top, actual streets/entrances, facing indicator and green walkable route with rerouting. Optional expanded map; navigation should not require opening it.
3. Attractive phone: consistent app icons, wallpaper, balanced spacing, concise screens and compact HUD.
4. A convincing furnished apartment with distinct rooms, usable furniture, correctly aligned activity animations and saved decoration.
5. Home -> physical doorway -> street -> playable job/shop/social venue -> return home. Keep joystick, contextual action, camera controls and delivery payment safeguards.
6. First finish an appealing connected experience; avoid expanding into empty decorative districts. Broader Lagos and other cities remain the direction.

Verify in rendered browser/device where available, separately from CPU checks and API/test doubles. Never describe passing geometry tests as proof of good visuals or Android performance. Request owner visual review of the actual playable milestone.
