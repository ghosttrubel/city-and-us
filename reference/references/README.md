Extract the `references` folder into the existing Lagos Street project beside package.json. This pack contains screenshots and one recording supplied by the user from Lagos Life as reference material.

## Firm direction
Preserve the CURRENT Lagos Street character design, model system, animation style and customisation developed locally in VS Code. The user likes that character. Do not revert to an earlier ZIP or replace it to resemble the characters in these screenshots. Appearance-flow screenshots demonstrate interface structure only.

Use these references to understand interactions, onboarding, interiors, phone navigation, location activities, transport, feedback and city presentation. Build an original Lagos Street interface, text, environments and assets. These images are references, not textures or screens to embed in the released game. Branded locations or campaigns in these images are not partnerships of Lagos Street.

## What to improve
- Clearer visual hierarchy and fewer overlapping notifications; one skippable tutorial step at a time.
- Interactive home objects: bed, cooker, bathroom, study desk and wardrobe, connected to needs and skill progress.
- Meaningful occupations, short tasks, progression, life goals and homes with different rent/interiors.
- Organised phone: working sections first; disclose unimplemented features honestly.
- Readable maps, useful destinations and transport choices with clear cost and time.
- Responsive portrait/landscape layouts, keyboard/mouse and touch, adjustable graphics, measured real-device performance. Do not claim support for every device without testing.
